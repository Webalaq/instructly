# Instructly

Booking, lesson notes, progress tracking, and WhatsApp reminders for UK driving instructors.

## Stack

Next.js 15 · TypeScript · Tailwind · shadcn/ui · Supabase · Stripe · Twilio · Vercel

## Getting started

```bash
pnpm install
cp .env.example .env.local   # fill in your keys
pnpm dev
```
